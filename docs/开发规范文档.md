## 一、版本固定策略

### 1.1 基准版本

- **版本哈希**：25e32e6
- **提交时间**：2026-05-28 12:24:46 UTC（北京时间 20:24:46）

- **版本说明**：此版本为所有后续开发的基准版本

### 1.2 分支管理

```
main (稳定版本)
  └─ 基于 25e32e6，作为生产环境分支
  └─ 仅接受从 develop 合并的稳定版本

develop (开发版本)
  └─ 基于 25e32e6 创建
  └─ 所有新功能开发都在此分支进行
  └─ 定期合并到 main 分支发布

feature/* (功能分支)
  └─ 从 develop 分支创建
  └─ 功能开发完成后合并回 develop

hotfix/* (紧急修复分支)
  └─ 从 main 分支创建
  └─ 修复完成后同时合并到 main 和 develop
```

### 1.3 版本标签规范

```bash
# 发布稳定版本
git tag -a v1.0.0 -m "正式发布版本 v1.0.0，基于 25e32e6"
git push origin v1.0.0

# 后续版本
git tag -a v1.1.0 -m "功能更新 v1.1.0"
git tag -a v1.2.0 -m "功能更新 v1.2.0"
```

## 二、开发流程

### 2.1 日常开发

```bash
# 1. 确保在 develop 分支
git checkout develop

# 2. 拉取最新代码
git pull origin develop

# 3. 创建功能分支
git checkout -b feature/your-feature-name

# 4. 开发完成后提交
git add .
git commit -m "feat: 描述你的功能"

# 5. 推送到远程
git push origin feature/your-feature-name

# 6. 创建 Pull Request 到 develop 分支
```

### 2.2 功能发布

```bash
# 1. 切换到 develop 分支
git checkout develop

# 2. 合并功能分支
git merge feature/your-feature-name

# 3. 测试验证通过后，合并到 main
git checkout main
git merge develop

# 4. 添加发布标签
git tag -a v1.x.x -m "版本说明"

# 5. 推送所有分支和标签
git push origin main develop --tags
```

## 三、Web 端开发规范

### 3.1 技术栈

- **框架**：React 18 + TypeScript
- **构建工具**：Vite 8.x
- **样式**：Tailwind CSS
- **动画**：Framer Motion
- **路由**：React Router 6
- **图标**：Lucide React

### 3.2 目录结构

```
opmaster-web/src/
├── assets/              # 静态资源
├── components/          # React 组件
│   ├── common/         # 通用组件
│   ├── home/           # 首页组件
│   └── ...
├── data/               # 数据文件
├── pages/              # 页面组件
├── store/              # 状态管理
├── App.tsx             # 应用入口
└── main.tsx            # 渲染入口
```

### 3.3 组件开发规范

```tsx
// 组件命名：PascalCase
// 文件命名：PascalCase.tsx

// 示例组件
import { motion } from 'framer-motion';
import { ComponentProps } from 'react';

interface ComponentNameProps {
  title: string;
  onAction?: () => void;
}

export default function ComponentName({ title, onAction }: ComponentNameProps) {
  return (
    <motion.div
      initial={{ opacity: 0 }}
      animate={{ opacity: 1 }}
      className="container"
    >
      <h1>{title}</h1>
      <button onClick={onAction}>Action</button>
    </motion.div>
  );
}
```

### 3.4 ColorOS 16 设计规范

#### 颜色系统
- **OPPO Orange**：`#FF6B35`
- **Hasselblad Orange**：`#D4A574`
- **中性色**：Neutral 100-900

#### 字体规范
- **标题**：Bold/Heavy, 24-48px
- **正文**：Regular/Medium, 14-18px

#### 间距系统
- **基础单位**：4px
- **组件间距**：8px, 16px, 24px, 32px
- **页面边距**：16px (移动端), 32px (桌面端)

#### 圆角规范
- **小**：8px（按钮、标签）
- **中**：16px（卡片、输入框）
- **大**：24px（模态框、底部弹窗）
