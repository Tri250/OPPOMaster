## 技术架构要点

### 前端技术栈
- React 18 + TypeScript
- Framer Motion（ColorOS 16 动效）
- Tailwind CSS（设计系统）
- React Router（路由）

### 设计规范
- ✅ ColorOS Design 3.0 无边界设计
- ✅ OPPO Orange × Hasselblad Orange 品牌色
- ✅ 玻璃态效果与流体动效
- ✅ 折叠屏自适应布局
- ✅ 移动端优先设计

### 数据结构
- Preset 实体：16 项核心参数
- 三维分类：风格 × 场景 × 机型
- 双引擎搜索：全文 + 语义
