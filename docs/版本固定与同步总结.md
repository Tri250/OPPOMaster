## 📋 开发流程

### 日常开发

```bash
# 1. 确保在 develop 分支
git checkout develop

# 2. 拉取最新代码
git pull origin develop

# 3. 创建功能分支
git checkout -b feature/your-feature

# 4. 开发并提交
git add .
git commit -m "feat: 描述功能"
git push origin feature/your-feature

# 5. 创建 Pull Request
# 访问：https://github.com/Tri250/OPPOMaster/pull/new/feature/your-feature
```

### 发布流程

```bash
# 1. 合并到 develop
git checkout develop
git merge feature/your-feature
git push origin develop

# 2. 测试验证通过后，合并到 main
git checkout main
git merge develop

# 3. 添加版本标签
git tag -a v1.x.x -m "版本说明"

# 4. 推送
git push origin main --tags
```
