## 一、设计原则与指导思想

### 1.1 核心设计理念

基于ColorOS 16 Aqua Design水生设计语言，结合哈苏专业摄影美学，打造「**纯净自然、高效直观、专业深度、系统融合**」的用户体验。

### 1.2 设计优先级原则

| 原则 | 权重 | 说明 |
|------|------|------|
| 用户价值密度 | 40% | 单位复杂度带来的体验提升 |
| 技术依赖关系 | 25% | 底层能力优先于上层功能 |
| 品牌差异化 | 20% | 体现OPPO摄影竞争力的特色功能 |
| 市场窗口 | 15% | 竞品动态和用户期待 |

#### 详细设计规范

##### F001 悬浮窗滤镜渲染引擎
- **设计目标：** 实时滤镜渲染，支持GPU加速
- **技术规格：**
  - 渲染延迟：< 50ms
  - 支持滤镜数量：≥ 100个同时加载
  - 帧率目标：30fps (预览), 60fps (录制)
- **实现方案：**
  - 使用WebGL进行GPU加速渲染
  - 滤镜采用LUT（3D Lookup Table）方案
  - 支持实时参数调节

##### F002 滤镜参数解析器 (LUT/JSON)
- **设计目标：** 支持多种参数格式
- **数据格式：**
```json
{
  "metadata": {
    "name": "哈苏自然色彩",
    "author": "OPPO",
    "version": "1.0",
    "category": "风光",
    "hncs_certified": true
  },
  "parameters": {
    "exposure": { "value": 0.0, "min": -3.0, "max": 3.0 },
    "contrast": { "value": 12, "min": -50, "max": 50 },
    "saturation": { "value": -8, "min": -50, "max": 50 },
    "temperature": { "value": 5200, "min": 2000, "max": 8000 }
  }
}
```

##### F004 悬浮窗显示与拖拽
- **设计规范：**
  - 默认尺寸：280×80dp
  - 最小尺寸：200×60dp
  - 最大尺寸：360×120dp
  - 圆角：16dp
  - 背景：rgba(18,18,18,0.85) + backdrop-blur: 16px
- **手势交互：**
  - 拖拽移动：单指按住任意位置
  - 固定位置：长按2秒锁定
  - 重置位置：双击回到右上角

##### F006 滤镜分类浏览
- **分类体系：**
  | 分类 | 数量 | 标签色 | 应用场景 |
  |------|------|--------|----------|
  | 全部 | 48 | -- | -- |
  | 人像 | 12 | #EC4899 | 人像摄影 |
  | 风光 | 15 | #3B82F6 | 自然风景 |
  | 美食 | 8 | #FFB347 | 美食摄影 |
  | 夜景 | 7 | #8B5CF6 | 夜景摄影 |
  | 胶片 | 6 | #2DB47A | 胶片风格 |
- **布局规范：**
  - 移动端：2列网格
  - 平板端：3列网格
  - 桌面端：4-6列网格
  - 卡片尺寸：1:1 正方形

##### F007 大师参数库卡片浏览
- **卡片规格：**
  - 尺寸：160×120dp (预览)
  - 圆角：16dp
  - 毛玻璃背景
- **卡片状态：**
  - 默认态
  - Hover态：scale(1.03)
  - 选中态：边框2dp #00C853
  - 收藏态：心形填充

##### F008 一键应用大师参数
- **交互规范：**
  - 点击应用按钮 → 参数立即生效
  - 响应时间：< 300ms
  - 成功反馈：Toast提示 + 动效
