## 核心功能说明

### 原生相机参数自动填入
解决用户"手动输入参数"的最高频痛点，从"参数参考工具"升级为"参数执行工具"。

**技术实现：**
- 基于安卓无障碍服务，无Root、合法合规
- 针对六大品牌原生相机大师模式
- 自动填充所有基础/专业参数
- 兜底方案：一键复制参数到相机内粘贴

### 悬浮窗系统
解决ColorOS/小米等系统悬浮窗无法开启、无法显示在相机上层的核心功能失效问题。

**技术实现：**
- 多悬浮窗类型兼容方案
- 针对四大厂商定制权限逻辑
- 适配率从30%提升到95%+

### 预设分类与搜索
多维度分类体系，快速找到心仪预设。

**功能特性：**
- 按风格分类（胶片/复古/清新等）
- 按场景分类（人像/美食/风光等）
- 全文搜索支持

### 预设生态
内置预设编辑器+一键社区贡献系统。

**功能特性：**
- 预设编辑器
- 一键贡献到社区
- 预设排行榜

### 多格式预设导入导出
支持主流修图工具预设格式。

**支持格式：**
- LUT文件（.cube）
- 泼辣修图预设
- Lightroom预设
- JSON格式
- 二维码分享
